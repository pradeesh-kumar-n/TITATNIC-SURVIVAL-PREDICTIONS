About the model

  • Pipeline from the repository: median imputation and scaling for numbers, constant imputation and one-hot encoding for categories, then a RandomForestClassifier.
  • Three engineered features: passenger title parsed from the name (rare titles merged), family size, and an alone flag.
  • Best parameters found by GridSearchCV: max_depth=10, min_samples_leaf=1, min_samples_split=6, n_estimators=100.
  • Accuracy figures come from running src/titanic/train.py on train.csv with scikit-learn 1.9.1 and seed 42. The demo forest is trained on all 891 rows and exported tree by tree, then evaluated in JavaScript. It matches scikit-learn's probabilities within 0.00001 on a spot check of 40 passengers.
  • The demo forest has seen every passenger it was trained on, so its probabilities run more extreme than the 83% cross-validated accuracy suggests. Read 99% as "almost every similar passenger survived".
  • This is an educational model on a small historical dataset. It describes patterns in 1912 records and says nothing about any real person.
